# 🕒 pomodoro-cli

Rust製のシンプルなポモドーロタイマーCLIツールです。  
作業時間・休憩時間・繰り返し回数を指定し、各セットごとの開始・終了予定時刻も表示します。

## 📦 特徴

- ✅ 作業時間・休憩時間・セット回数をCLI引数で指定可能
- 🕒 全体および各セットの開始・終了時刻を24時間表記で表示
- 🎨 色付き・絵文字付きで視認性の高い出力
- 📚 `clap` による柔軟な引数パース
- 🧭 実時間に基づいた正確なタイマー計測

## 🚀 インストール方法

### Rustがインストールされている場合

```sh
git clone https://github.com/your-username/pomodoro-cli.git
cd pomodoro-cli
cargo build --release
```

バイナリは `target/release/pomodoro-cli` に生成されます。

## 📝 使い方

```sh
pomodoro-cli --work 25 --break 5 --repeat 4
```

### オプション一覧

| オプション        | 内容              | 例           |
|-------------------|-------------------|--------------|
| `-w`, `--work`    | 作業時間（分）    | `--work 25`  |
| `-b`, `--break`   | 休憩時間（分）    | `--break 5`  |
| `-r`, `--repeat`  | セット回数        | `--repeat 4` |

## 💻 実行例

```
🎯　ポモドーロ開始：「作業 25分 → 休憩 5分」 × 2セット
🕒　全体：14:03 ～ 14:58

▶️　セット 1 開始（14:03 ～ 14:33）
    🛠　作業中: 00:25
    ☕　休憩中: 00:05
========================================
    ✅　セット 1/2 完了
========================================

▶️　セット 2 開始（14:33 ～ 15:03）
    🛠　作業中: ...
```
